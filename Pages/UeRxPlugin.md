# UeRxPlugin

- 최대한 간단한 모드로
    - 간단한 문법으로 사용가능하도록
    - lambda 적극 활용되게
- 최대한 간단한 기능
    - 사용이 복잡해질 수 있다면 기능제거도 고려
- Dispose가 간단히 처리되도록

- 구현기능
    - Observable
        - Subscribe
        - TimerFrame(int)
        - EveryUpdate
        - EveryLateUpdate
        - EveryEndOfFrame
    - Dispoable
        - Dispose
- 초기에는 Trigger는 거의 없게
